# Kizy#4634 · Discord.py
----------
### Descripción
Kizy es un bot del género femenino multifuncional, capaz de reproducir música, moderar, y entre otros comandos que posee, como algunas utilidades.

Nombre del Proyecto
Breve descripción o introducción del proyecto.

Funcionalidades
----------
### Acciones
El bot ofrece una variedad de acciones divertidas que pueden realizarse en los miembros del servidor, como bofetearlos (`accion`) o abofetearlos (`pegar`).

----------
### Información
Proporciona información útil sobre los miembros del servidor, como su avatar (`avatar`), banner (`banner`), información general (`serverinfo`, `userinfo`), y más. También ofrece ayuda (`ayuda`) sobre los comandos disponibles.

----------
### Música
El bot puede reproducir música en canales de voz. Ofrece comandos para reproducir canciones (`play`), mostrar la lista de reproducción (`queue`), pausar/resumir la reproducción (`pause`, resume), y más.

----------
### Utilidades
Ofrece una variedad de utilidades útiles, como codificar/decodificar texto en Base64 (`base64`), lanzar una moneda (`coinflip`), obtener la fecha actual (`date`), lanzar un dado (`dice`), realizar operaciones matemáticas (`math`), realizar consultas de DNS (`nslookup`), generar contraseñas aleatorias (`passwd`), y más.

----------
### Moderación
Proporciona funciones básicas de moderación, como bannear (`ban`), expulsar (`kick`), eliminar mensajes (`cls`), establecer un "timeout" a un usuario (`timeout`), retirar el ban (`unban`), retirar el timeout (`untimeout`), retirar advertencias (`unwarn`), y advertir a los usuarios (`warn`).

----------
### Actualizaciones
El comando updates muestra la lista de actualizaciones del bot para mantener a los usuarios informados sobre las últimas mejoras y cambios.
